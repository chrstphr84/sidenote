Google export

Export your notes straight into a Google Doc or Sheet. This uses your own Google OAuth client — see the steps below.

OAuth client ID
From Google Cloud → Credentials (a client ID isn't a secret)
Redirect URI
Add this under “Authorized redirect URIs” in Google Cloud
—
Test connection
Authorize once and confirm it works
Setup steps
  1. Google Cloud Console → create/select a project.
  2. APIs & Services → enable Google Drive API.
  3. OAuth consent screen: External, add yourself as a Test user, add scope drive.file.
  4. Credentials → Create OAuth client ID → Web application → add the Redirect URI above.
  5. Paste the Client ID here, then use Export → Google Doc / Google Sheet.
